# Security Policy

## Reporting a Vulnerability

The MangaDock team and contributors take the security of our application and users seriously.

If you believe you have found a security vulnerability in MangaDock, please do not disclose it publicly via GitHub issues or discussions.

Instead, please send an email to:
- `satiricalguru` at [jatinjio1212@gmail.com](mailto:jatinjio1212@gmail.com)

Please include:
- A description of the issue and potential impact
- Detailed steps to reproduce or proof-of-concept
- Any relevant logs, screenshots, or code snippets

We will acknowledge receipt within 48 hours and work on a fix as quickly as possible.
